# Research Frontier Map

This file defines areas to monitor and questions to refine. It is not a claim that any listed question is currently unsolved; literature review is required before selecting a research problem.

## 1. Learning dynamics and generalisation

Questions to investigate:
- Why can generalisation improve after prolonged training?
- How do optimisation, architecture, data, and initialisation interact?
- When do neural networks learn features versus behave like fixed-feature models?
- How do scaling relationships change across data and compute regimes?

## 2. Internal representations

Questions to investigate:
- How are concepts represented across layers and components?
- When do features become distributed or superposed?
- What can causal interventions reveal that correlations cannot?
- How reliable are current feature-discovery methods?

## 3. Memory and continual learning

Questions to investigate:
- What should be stored in parameters versus external memory?
- How can a system update knowledge without destructive interference?
- How should memory retrieval, relevance, freshness, and provenance be evaluated?
- Which benchmarks distinguish memorisation from useful retention?

## 4. In-context learning and adaptation

Questions to investigate:
- What computations support adaptation from context?
- How do task structure and training distributions affect in-context behaviour?
- When does context function as temporary memory?

## 5. Computational neuroscience connections

Questions to investigate:
- Which learning principles are shared across biological and artificial systems?
- What can neuroscience-inspired constraints teach us about efficient learning?
- Which analogies are explanatory, and which are misleading?

## Research selection checklist

Before committing to a project:
- [ ] Read recent surveys and primary papers.
- [ ] Define the exact research question.
- [ ] Identify the strongest relevant baseline.
- [ ] State what result would disconfirm the hypothesis.
- [ ] Check data, compute, and time feasibility.
- [ ] Define metrics and controls before running experiments.
- [ ] Record known limitations and alternative explanations.

## Evidence labels

Use these labels in notes and digests:
- **Established:** supported by substantial converging evidence.
- **Peer-reviewed:** published through a scholarly review process.
- **Preprint:** publicly available but not necessarily peer-reviewed.
- **Preliminary:** early or limited evidence.
- **Hypothesis:** a proposed explanation requiring testing.
- **Speculation:** an idea without sufficient supporting evidence.

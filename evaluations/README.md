# Learning and Research Evaluations

## Concept mastery rubric

Score each dimension from 0 to 4 and attach evidence.

| Score | Meaning |
|---:|---|
| 0 | Cannot explain the concept yet |
| 1 | Recognises terms but explanation is unreliable |
| 2 | Gives a mostly correct explanation with prompts |
| 3 | Explains and applies independently |
| 4 | Derives, critiques, and transfers the idea to a new setting |

## Dimensions

- Conceptual accuracy.
- Mathematical reasoning.
- Ability to derive key results.
- Implementation ability.
- Ability to identify assumptions.
- Ability to diagnose failure modes.
- Ability to connect ideas across papers.
- Ability to design a valid experiment.

## Assessment rule

A high score requires evidence such as a derivation, implementation, oral/written explanation, or experimental analysis. Self-reported confidence is useful context but is not sufficient evidence of mastery.
